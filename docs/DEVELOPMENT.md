# Сборка и проверка

Базовый исходный коммит: `501b6ff` (Remnant Save Guardian 1.4.2). Версия русского выпуска: `1.4.3`. Игровая база: ревизия `18`.

## Сборка

На Windows с .NET 8 SDK:

```powershell
dotnet restore RemnantSaveGuardian.sln
pwsh -File scripts/Verify-Localization.ps1
pwsh -File scripts/Build-Release.ps1
```

Скрипт выпуска создаёт автономную папку Windows x64, ZIP и SHA-256 в `artifacts`. В ZIP входят лицензия, README, список изменений и русские спутниковые ресурсы.

## Скриншоты реального интерфейса

```powershell
dotnet build RemnantSaveGuardian.sln -c Release
dotnet RemnantSaveGuardian/bin/Release/net8.0-windows/RemnantSaveGuardian.dll --screenshots docs/images
```

Режим `--screenshots` запускает настоящий WPF-интерфейс с демонстрационными строками резервных копий и событиями встроенной базы. Он отключает обновления, автоматическое копирование и запись настроек, работает с отдельными каталогами внутри `docs/images/.demo` и автоматически закрывается после экспорта.

PNG создаются WPF через RenderTargetBitmap из отрисованных страниц: резервные копии, анализатор, настройки. Это снимки нашего интерфейса, а не макеты или обработанные изображения оригинала. Режим также записывает `localization-audit.json` со списком предметов без русского названия; для выпуска этот список должен быть пустым.

## Проверка перевода

`Verify-Localization.ps1` проверяет полноту ресурсов, уникальность ключей, непустые значения, сохранность подстановок, русский текст всех подсказок, язык по умолчанию и неизменность структуры игровых идентификаторов относительно исходного коммита.

## Wiki

Исходники опубликованной wiki находятся в `docs/wiki`. Страницы `Home` и `Help` соответствуют структуре документации прежнего RemnantSaveManager, но описывают Remnant II и текущую русскую версию Guardian. Отдельная wiki исходного RemnantSaveGuardian не была доступна при подготовке выпуска. Изображения загружаются из `docs/images` нашего репозитория.
